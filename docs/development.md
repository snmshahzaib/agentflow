# Development

## Prerequisites

| Tool | Version used |
|---|---|
| Python | 3.12 (pinned; `backend/.python-version`) |
| uv | 0.13+ |
| Node | 24 LTS |
| pnpm | 9+ |
| Docker Desktop | required for the compose stack |
| PostgreSQL / Redis | provided by compose, or local instances |

## Fastest path

```bash
cp .env.example .env     # edit; .env is gitignored
docker compose up --build
```

Frontend http://localhost:8080 · API docs http://localhost:8000/docs · readiness
http://localhost:8000/ready

Default configuration needs **no API keys**: `LLM_PROVIDER=stub` and `SEARCH_PROVIDER=fixture`
give a deterministic offline system.

## Outside Docker

```bash
cd backend
cp .env.example .env
uv sync --extra dev
uv run alembic upgrade head
uv run uvicorn app.main:app --reload --port 8000     # terminal 1
uv run arq app.workers.settings.WorkerSettings       # terminal 2
```

```bash
cd frontend
cp .env.example .env.local
pnpm install
pnpm dev                                             # terminal 3 — http://localhost:5173
```

## Quality gates

```bash
cd backend
uv run ruff check . && uv run ruff format --check .
uv run mypy app
uv run lint-imports        # architecture boundaries
uv run pytest
uv run pytest -m "not integration"    # no Postgres/Redis needed
```

```bash
cd frontend
pnpm lint && pnpm test && pnpm build
```

Or everything at once, from the repository root:

```bash
make verify
```

`make verify` is the honest pre-claim gate — never report a milestone complete without it, and
never report it as passing without pasting its real output.

## Commit workflow

`pre-commit` is installed as a Git hook and runs gitleaks, hygiene checks, ruff, mypy,
import-linter and the project guards. Install it once:

```bash
uv tool install pre-commit
pre-commit install
pre-commit run --all-files     # first run also warms the hook environments
```

Never bypass a hook with `--no-verify`.

## Migrations

```bash
cd backend
uv run alembic revision --autogenerate -m "add x"   # review the generated file before committing
uv run alembic upgrade head
uv run alembic downgrade -1                          # both directions must work
```

Autogenerated migrations are reviewed by hand: Alembic does not reliably detect type changes,
constraint renames or server defaults.
